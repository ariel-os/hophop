Most common abbreviations used in the context of DECT-2020/NR+ according to ETSI TS 103 636-1

- **ARQ**: Automatic Repeat reQuest
- **BCC**: Broadcast Control
- **BCCH**: Broadcast Control Channel
- **BSC**: Beacon Scanning Control
- **CCC**: Connection Configuration Control
- **CCCH**: Connection control Channel
- **CP-OFDM**: Cyclic-Prefix [Orthogonal Frequency Division Multiplexing](https://en.wikipedia.org/wiki/Orthogonal_frequency-division_multiplexing) (method for improving OFDM reception in multi-path environments)
- **CVG**: Convergence (layer)
- **DCCH**: Dedicated Control Channel
- **DCH**: Dedicated Channel
- **DL**: Downlink
- **DLC**: Data Link
- **DTCH**: Dedicated Traffic Channel
- **EP**: Endpoint
- **FDMA**: [Frequency Division Multiple Access](https://en.wikipedia.org/wiki/Frequency-division_multiple_access)
- **FEC**: [Forward Error Correction](https://en.wikipedia.org/wiki/Error_correction_code)
- **FFT**: Fast Fourier Transform
- **FT**: Fixed Termination point
- **GI**: Guard Interval
- **LBT**: Listen Before Talk
- **MAC**: Medium Access Control
- **MIMO**: [Multiple Input Multiple Output](https://en.wikipedia.org/wiki/MIMO)
- **MTCH**: Multicast (Broadcast) Traffic Channel
- **NR**: New Radio
- **OFDM**: [Orthogonal Frequency Division Multiplexing](https://en.wikipedia.org/wiki/Orthogonal_frequency-division_multiplexing)
- **PCC**: Physical Control Channel
- **PCCH**: Physical Control Channel
- **PCH/BCH**: Paging and Broadcast Channel
- **PDC**: Physical Data Channel
- **PHY**: Physical layer
- **PT**: Portable Termination point
- **PTC**: Paging Transmission Control
- **RAC**: Random Access Control
- **RACH**: Random Access Channel
- **RD**: Radio Device
- **RF**: Radio Frequency
- **RSSI**: Received Signal Strength Indicator
- **RX**: Receiver
- **RX-TX**: Receive-Transmit
- **SAP**: Service Access Point
- **TDMA**: [Time Division Multiple Access](https://en.wikipedia.org/wiki/Time-division_multiple_access)
- **TX**: Transmitter
- **UE**: User Equipment
- **URLLC**: Ultra-Reliable Low Latency Communications
